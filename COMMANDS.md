# Telegram commands

Все команды принимает только подключённый владелец аккаунта.

## Проверка и справка

### `пинг`

Проверяет, что userbot отвечает.

```text
пинг
```

### `.мышление` или `/reasoning`

Показывает текущую модель, активный уровень reasoning и уровни, доступные
для этой модели.

```text
.мышление
/reasoning
```

### `.скорость`

Показывает текущий service tier Codex.

```text
.скорость
```

Обычный режим — `normal` (`default`). Быстрый режим — `fast` (`priority`),
если он поддерживается выбранной моделью.

```text
.скорость normal
.скорость fast
```

Русские и дополнительные алиасы:

```text
.скорость обычно
.скорость быстро
.скорость 1.5x
```

## Модель Codex

### `.модель`

Показывает каталог доступных моделей и поддерживаемые уровни reasoning.

```text
.модель
```

### `.модель <slug>`

Выбирает модель для следующих обращений к Codex.

```text
.модель gpt-5.6-sol
```

## Прямое обращение к Codex

### `ам <текст>`

Отправляет текст в текущую persistent-сессию Codex. История диалога
сохраняется между перезапусками приложения.

```text
ам привет
ам Покажи последние 20 сообщений из чата <chat_id>
```

Если запрос явно касается Telegram, Codex использует MCP-инструменты
`pyrogram_mcp`. Обычный текст после `ам` не пересылается в Telegram.

## Как показывать справку

Этот файл является единственным актуальным справочником команд. Если владелец
просит показать команды, список команд или помощь, Codex должен обратиться к
`COMMANDS.md` и отправить ему актуальное содержимое или нужный раздел файла,
не восстанавливая список по памяти.
